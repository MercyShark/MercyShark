I'm Rishabh. I love system design and web development, and I have created my own home server.

It’s an 8-core, 16GB RAM machine running Ubuntu Server (headless), used to host my personal projects, APIs, and containerized applications.

Key features:
- 8-core processor for multitasking  
- 16GB RAM for smooth multi-service operation  
- Ubuntu Server for stability and remote management  
- Self-hosted setup for learning and experimentation  
- Container management using [Portainer](https://www.portainer.io/)
